# 聖水小戰場

給完全沒玩過即時對戰卡牌遊戲的新手練習用的小遊戲，用來學會四件事：

1. 聖水要慢慢花，不要亂花
2. 手牌會輪替，要記得下一張是什麼
3. 聖水滿了不用就是浪費
4. 認識「進攻核心單位」和它的剋制關係，要看對手出什麼來應對

這是學校作業（Vibe Coding 做互動網頁）的作品，已用 GitHub Pages 公開：
**https://caichenlin.github.io/vibe-coding-game/**

---

## 一、硬性限制（不可違反）

- 遊戲只有**單一 `index.html`**，CSS 和 JavaScript 都寫在裡面
- **不使用任何外部資源**：不用 CDN、外部圖片、外部字型、套件、音效檔
- 單位、人物、卡面圖示用 **emoji 加 CSS 顏色**；城堡、砲塔、橋、草地、特效用 `<canvas>` 程式繪製；音效用 Web Audio 即時合成。不使用任何官方卡面、Logo、原遊戲名稱或原卡牌名稱（頁面上的牌名都用本文件取的名字）
- 頁面標題和文字使用**繁體中文**，不要出現簡體字
- 手機（直向）和電腦都能操作，同時支援滑鼠和觸控
- 直接用瀏覽器開啟檔案就能玩，不需要伺服器

## 二、開發流程規則

- 原訂分三個版本做，**每做完一版就停下來**，等我確認再做下一版
- 實際進行方式：第 1 版完成後反覆試玩、調整（1.0～1.5），過程中把第 2 版的單位互動與電腦對手提前做完；之後做第 3 版（3.0）和畫面升級（3.1）。每一版的差異記在 `CHANGELOG.md`
- 每一版都必須能正常開啟、玩得下去
- 每版完成後回報：這版新增或修改了什麼、哪些地方我該測試。我會貼進作業的修改紀錄
- 每版結束前用本機開啟頁面檢查，確認 console 沒有錯誤
- 不確定的規則先問我，不要自己決定後直接往下做
- 程式碼加上簡單的中文註解，我要能看懂大概在做什麼

## 四、核心規則

| 項目 | 設定 |
|---|---|
| 聖水 | 上限 10，開局 5，每 2.8 秒回復 1 點 |
| 塔 | 雙方各 3 座：2 座公主塔（每條路一座）＋ 1 座國王塔（後方正中央） |
| 對戰時間 | 3 分鐘，無延長賽 |
| 開始方式 | 按「開始對戰」（或結算畫面的「再玩一次」）後，先倒數 3 秒；倒數期間不能下牌、不回聖水、不計時 |

### 塔的數值

| 塔 | 位置 | 血量 | 傷害 | 攻速(秒) | 射程 | 說明 |
|---|---|---|---|---|---|---|
| 公主塔 | x = 90／270，y = 150（敵）、530（我） | 1000 | 36 | 0.8 | 150（7.5 格） | 攻擊範圍內最近的敵方單位（地面、空中、砲塔都可以） |
| 國王塔 | x = 180，y = 95（敵）、585（我） | 1580 | 36 | 1.0 | 140（7 格） | 同上；一直都會攻擊（不做原遊戲的「受擊才啟動」） |

> 數值參考原遊戲 11 級：血量和傷害統一 ÷3.05（讓公主塔維持 1000 血），射程用格數 × 20 px。塔的射程從塔中心算；單位打塔時，射程從塔的邊緣（受攻擊範圍 35 px）算。

### 勝負判定

1. 任一方國王塔血量歸 0 → 對方**立刻獲勝**
2. 時間到 → 比較「摧毀敵方塔的數量」，多者勝
3. 塔數相同 → 比較己方剩餘塔血總和，高者勝；仍相同才算平手

### 塔的攻擊目標

- 單位下場時，依下牌位置離哪一路比較近（x = 90 或 270），決定「自己這一路」
- 一般單位預設攻擊**自己這一路的敵方公主塔**；該路公主塔被摧毀後，改為朝**敵方國王塔**前進並攻擊
- 只打建築的單位（🐗 衝鋒豬、💣 炸彈兵）改去打**最近的敵方建築**：自己這一路的塔，或比塔更近的敵方 🔫 砲塔

### 手牌循環

- 固定 8 張牌組，開局隨機洗牌（電腦對手有自己的一副，規則相同）
- 手上 4 張，另有 1 張「下一張」預覽，其餘在牌隊裡
- 出牌後，該牌進入牌隊尾端，「下一張」補進手牌，牌隊最前面的牌成為新的「下一張」

### 下牌方式

1. 點選一張手牌（金框、往上浮）。此時不能下牌的區域蓋上紅色斜線，可下區域的邊緣畫流動的白色虛線
2. 用滑鼠時，游標位置會顯示下牌預覽（遠程單位和砲塔會顯示射程圈；不能下的位置顯示紅色 ✕）
3. 點可下牌區域的任意位置，單位就出現在**點的位置**（x 會限制在 20～340；3 隻一組的牌左右間隔 12 px 並排）
   - 可下牌區域：自己半場（河的下方，包含國王塔後面），但不能下在河裡或塔上
   - 敵方某一路公主塔被摧毀後，那一路的敵方半場前段（從河邊到 y = 170）也可以下牌
4. 聖水不足的牌變暗，點了不會被選取，畫面顯示「聖水不夠」，教練也會提醒
5. 再點一次已選的牌可取消選取
6. 錯誤提示：沒選牌就點競技場 →「先點一張手牌」；倒數中 →「還沒開始，等倒數結束」；點河或塔上 →「不能下在塔上或河裡」；點其他不能下的地方 →「紅色區域不能下牌」

### 單位基本行為

- 地面單位沿自己這一路前進，過河時走那一路的橋（空中單位和衝鋒豬可以直接過河）
- 射程內有可攻擊的敵方單位就打最近的那個（停下來打）
- 射程內沒有敵方單位、但已經在塔的範圍內 → 攻擊塔
- 都沒有時，**索敵範圍（110 px）內**看到可攻擊的敵方單位就追過去；看不到就繼續往塔前進
- 單位血量歸 0 就消失

## 五、進攻核心單位（Win Condition）

**定義**：傷害高、**不會被路上的敵方單位分心**、直接去打塔的單位。

**牌組規則**：8 張牌裡至少放 2 張進攻核心單位。本牌組有 **2 張：🐗 衝鋒豬、💣 炸彈兵**。（🛡️ 坦克是會打單位的「前排肉盾」，不算進攻核心）

**設計參考**：原遊戲中「速度很快、只打建築、可以跳河」的主力推塔單位。數值是依原版 11 級比例縮放成本遊戲的尺度（血量和傷害 ÷3.05，射程 1 格 = 20 px，移速依原遊戲速度等級換算），不是照抄。

| 進攻核心單位 | 風格 | 怎麼用 | 怎麼防 |
|---|---|---|---|
| 🐗 衝鋒豬 | 快、只打建築、跳河 | 對手聖水少時直接衝塔；或跟在坦克後面 | 砲塔引開、小兵群攔截、法師輸出、靠塔打 |
| 💣 炸彈兵 | 衝塔自爆，一次性高傷害 | 用來補最後一擊，或炸掉塔前的敵方單位群 | 砲塔引開、小兵群在半路擊殺 |

**核心配合**：🛡️ 坦克（前排肉盾）先走、🐗 衝鋒豬跟後面。公主塔會先打最近的坦克，衝鋒豬就能多打幾下；坦克也會順手處理來防守的敵方單位。再加上 💚 遠程治療師補血，坦克能撐更久。

### 特殊規則細節

- **空中單位**：地面近戰單位（小兵群、衝鋒豬、坦克）和砲塔打不到；只有法師、塔、其他空中單位可以攻擊。空中單位可以飛過河，不用走橋
- **範圍傷害**：法師的攻擊對目標周圍半徑 30 內的**所有敵方單位**造成傷害（地面和空中都算）；打塔時，塔邊緣 30 px 內的敵方單位也會受傷
- **只打建築（不理單位）**：衝鋒豬（和炸彈兵）不會因為路上有敵方單位而停下或轉向，直接前往**最近的敵方建築**（自己這一路的塔，或比塔更近的砲塔）；但敵方單位和塔可以攻擊它
- **🔫 砲塔（建築）**：放下後不會移動，血量在 30 秒內平均減少到 0 後消失；攻擊射程內最近的敵方地面單位（不會追擊）；一般單位會把它當成可攻擊的目標；炸彈兵炸到它造成 300（和塔一樣，範圍從砲塔邊緣算）；治療師不會補它
- **跳河**：衝鋒豬不需要繞到橋上，可以直接過河
- **炸彈兵**：不攻擊單位，直接走向最近的敵方建築；**被塔打到**之後開始「倒扣血」（每秒 34）並加速為 2 倍（被單位打不會加速，所以小兵群、砲塔攔得住）；進入建築的範圍或血歸 0 時自爆，半徑 40 內（對塔、砲塔從邊緣算），對塔和砲塔 300 傷害、對敵方地面單位 150 傷害，炸彈兵本身消失；不傷害己方、不傷害空中單位
- **遠程治療師**：
  - 每 1.5 秒，治療射程（110 px，約 5.5 格）內「血量比例最低」的受傷友軍 50 點，不超過血量上限
  - 地面和空中友軍都可以治療；不能治療自己，也不能治療塔和砲塔
  - 平常跟在最近的友軍後方約 60 px（不會跟著其他治療師或砲塔）；沒有友軍時，像一般單位一樣往敵方塔前進（會過河），走到塔的射程內就停下，讓對方有機會解掉它
  - 治療時，治療師和目標之間畫一條綠線，目標頭上飄出「+50」，玩家看得出在補誰
  - 治療量（約每秒 33）低於公主塔傷害（約每秒 45），光靠補血頂不住塔，要搭配輸出
  - 不攻擊，但敵方單位和塔會攻擊它

### 單位互動（設計目的）

| 組合 | 結果 | 原因 |
|---|---|---|
| 小兵群 vs 衝鋒豬 | 小兵群佔優 | 數量多、攻速快，能很快把衝鋒豬打掉 |
| 法師 + 塔 vs 衝鋒豬 | 防守方佔優 | 衝鋒豬不理單位，邊衝邊被法師和塔打 |
| 衝鋒豬 + 坦克 | 進攻方佔優 | 塔先打坦克，衝鋒豬多打幾下 |
| 坦克 + 治療師 | 進攻方佔優 | 坦克被補血，在塔前撐更久 |
| 法師 vs 小兵群 / 蝙蝠群 | 法師佔優 | 範圍傷害一次打多隻 |
| 砲塔 vs 蝙蝠群 | 蝙蝠群佔優 | 砲塔只打地面，蝙蝠可以直接拆掉它 |
| 砲塔 vs 衝鋒豬 | 防守方佔優 | 衝鋒豬被吸去打砲塔，塔不會掉血 |
| 法師 vs 坦克 | 法師佔優 | 坦克攻速很慢（3.5 秒），法師撐得到把它打完 |
| 小兵群 vs 坦克 | 小兵群佔優 | 數量多、攻速快，坦克打得很慢，來不及清完小兵 |

| 砲塔 vs 炸彈兵 | 砲塔佔優 | 炸彈兵被吸過去，在半路就被砲塔打爆 |
| 治療師 vs 法師 / 炸彈兵 | 治療師吃虧 | 範圍傷害和爆炸會連它一起打到 |

## 七、電腦對手

- 有自己的聖水和自己的一副 8 張牌、手牌循環（規則與玩家完全相同，不作弊）
- 開局前 5 秒不出牌，給玩家反應時間
- **隨機出牌**：沒有需要防守的威脅時，每隔 3～6 秒（隨機）從負擔得起的手牌隨機挑一張
  - 一般牌：隨機選一路，下在 x = 路線 ±15 px、y = 240～310（自己半場靠河）
  - 砲塔：下在中間附近（x = 150～210、y ≈ 250）
  - 如果位置不能下（例如在塔上），就往自己後方每次退 15 px 找可以下的點；找不到就下在那一路河邊（y = 300）
- **會防守**：
  - 「威脅」= 已經過河（y < 340）、還沒處理過的玩家單位；有好幾個時，挑最靠近電腦塔的那個
  - 第一次看到威脅後 0.8 秒才反應（像真人一樣有反應時間）
  - 依下表順序，從手牌挑第一張「有在手上而且付得起」的剋制牌：

    | 玩家出 | 電腦優先用 |
    |---|---|
    | 🐗 衝鋒豬 | 🔫 砲塔 → 👥 小兵群 → 🧙 法師 |
    | 🛡️ 坦克 | 👥 小兵群 → 🧙 法師 → 🔫 砲塔 |
    | 💣 炸彈兵 | 🔫 砲塔 → 👥 小兵群 |
    | 🦇 蝙蝠群 | 🧙 法師 → 🦇 蝙蝠群 |
    | 👥 小兵群 | 🧙 法師 → 🦇 蝙蝠群 |
    | 💚 治療師 | 🧙 法師 → 🦇 蝙蝠群 |
    | 🧙 法師 | 👥 小兵群 → 🦇 蝙蝠群 |

  - 下牌位置：近戰單位擋在威脅正前方 45 px；遠程單位（法師）在前方 90 px；砲塔放在威脅和中線之間、前方 70 px
  - 有剋制牌但聖水不夠會等，最多 4 秒；手上沒有剋制牌就放棄，交給塔處理
  - 同一批出的（例如小兵群 3 隻，彼此 40 px 內）一起算處理過
  - 正在防守（有威脅還沒處理完）時不隨機出牌
- 測試工具的「🤖 電腦對手出牌」取消勾選時，電腦完全不出牌

## 八、新手教學提示

畫面上有一塊固定的「教練」區（頭像＋對話框，文字有打字效果，換新提示時會彈一下），依事件顯示一句白話提示：

| 時機 | 提示 |
|---|---|
| 開局 | 「點一張牌，再點你的半場來下牌」 |
| 每張牌第一次下牌後 | 介紹該牌的特色（見下表）；如果同時聖水不到 1，先顯示花光聖水的提示，下次再出這張才介紹 |
| 聖水到 10 且停留超過 2 秒 | 「聖水滿了會浪費，趕快出牌」（每次滿只提醒一次） |
| 聖水不足時點牌 | 「聖水不夠，等一下再出」 |
| 出牌後聖水不到 1 | 「花光聖水會讓你沒辦法應對，留一點」 |
| 敵方出 🐗 衝鋒豬 | 「敵方出了衝鋒豬！跑很快、只打建築。用砲塔把它引開、用小兵群去攔，或靠法師和塔來打」 |
| 敵方出 🛡️ 坦克 | 「敵方出了坦克！很耐打但打得很慢，用小兵群圍毆或法師來對付」 |
| 敵方出 🛡️ 坦克後 10 秒內出 🐗 衝鋒豬 | 「他們在配合：坦克吸引塔，衝鋒豬跟在後面，先處理衝鋒豬」 |
| 敵方出 🦇 蝙蝠群 | 「敵方出了蝙蝠！在空中，近戰打不到，要用法師」 |
| 敵方出 👥 小兵群 | 「敵方出了小兵群！數量多，法師的範圍傷害很有效」 |
| 敵方出 💣 炸彈兵 | 「敵方出了炸彈兵！會衝塔自爆，用砲塔把它引開，或用小兵群在半路攔住」 |

- 測試模式替敵方下牌時，也算「敵方出牌」

### 結算畫面

遊戲結束 0.7 秒後（讓爆炸特效播完）跳出結算畫面：

- 勝負橫幅：勝利（金色）、落敗（灰色）、平手（藍色）
- 雙方皇冠（摧毀幾座亮幾個）和勝負原因（例如「你摧毀了敵方國王塔！」「時間到！摧毀塔數 1 : 0」）
- 統計表：摧毀塔數、出牌次數、總花費聖水、浪費聖水（聖水已滿時溢出的量，小數 1 位）、平均每張牌費用（附牌組平均 3.63 方便比較）
- 教練依下列規則給一句建議（由上往下判斷）：
  - 浪費聖水 > 5：「你浪費了不少聖水，聖水滿的時候要記得出牌」
  - 平均費用 > 4：「你的出牌偏貴，可以多搭配便宜的牌」
  - 其他：「聖水運用得不錯，繼續保持」
- 按鈕：「再玩一次」（重新洗牌，直接開始倒數）、「回主畫面」（回到開始畫面）

- 名字 5 個字以上的牌（遠程治療師）字會縮小，不會擠出卡片
