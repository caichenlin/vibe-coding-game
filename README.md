# 聖水小戰場

給完全沒玩過即時對戰卡牌遊戲的新手練習用的小遊戲，用來學會四件事：

1. 聖水要慢慢花，不要亂花
2. 手牌會輪替，要記得下一張是什麼
3. 聖水滿了不用就是浪費
4. 認識「進攻核心單位」和它的剋制關係，要看對手出什麼來應對

這是學校作業（Vibe Coding 做互動網頁）的作品，最終要用 GitHub Pages 公開。

---

## 一、硬性限制（不可違反）

- 遊戲只有**單一 `index.html`**，CSS 和 JavaScript 都寫在裡面
- **不使用任何外部資源**：不用 CDN、外部圖片、外部字型、套件
- 圖示一律用 **emoji 加 CSS 顏色**，不使用任何官方卡面、Logo、原遊戲名稱或原卡牌名稱（頁面上的牌名都用本文件取的名字）
- 頁面標題和文字使用**繁體中文**，不要出現簡體字
- 手機（直向）和電腦都能操作，同時支援滑鼠和觸控
- 直接用瀏覽器開啟檔案就能玩，不需要伺服器

## 二、開發流程規則

- 分三個版本做，**每做完一版就停下來**，等我確認再做下一版
- 每一版都必須能正常開啟、玩得下去
- 每版完成後回報：這版新增或修改了什麼、哪些地方我該測試。我會貼進作業的修改紀錄
- 每版結束前用本機開啟頁面檢查，確認 console 沒有錯誤
- 不確定的規則先問我，不要自己決定後直接往下做
- 程式碼加上簡單的中文註解，我要能看懂大概在做什麼

## 三、畫面

直向競技場，邏輯座標 360 × 680（1 格 ≈ 20 px），用 `<canvas>` 繪製並隨視窗等比縮放。國王塔後面留約 3 格空間，可以「沉底」（下在國王塔後面）。

```
┌────────────────────┐
│     👑 敵方國王塔    │  y = 95
│  🏰 敵公主塔  🏰 敵公主塔 │  y = 150（左路 x=90、右路 x=270）
│                    │
│ ~~~~~~~河~~~~~~~~~ │  y = 340，兩條橋在左右路
│                    │
│  🏰 我公主塔  🏰 我公主塔 │  y = 530
│     👑 我方國王塔    │  y = 585（後面到 680 都可以下牌）
├────────────────────┤
│ 聖水條 ████ 7        │
│ [牌1][牌2][牌3][牌4]  下一張：[牌5] │
│ 教練提示區（第 3 版）  │
└────────────────────┘
```

- 左右兩條路線（x ≈ 90 與 x ≈ 270），中間有河，兩條路各一座橋
- 頂部顯示剩餘時間（3:00 倒數，最後一分鐘變紅）和雙方已摧毀的塔數（用皇冠表示）
- 下方的 UI 用一般 HTML 元素（聖水條、手牌、提示區），不畫在 canvas 裡
- 每座塔和每個單位都有血條（單位受傷後才顯示）
- 視覺風格接近原遊戲（只用 CSS、emoji、程式繪製）：
  - 開始畫面（Logo、牌組預覽、玩法說明、開始按鈕）；結算畫面有勝負橫幅、統計、「再玩一次」「回主畫面」
  - 競技場：草地紋理、土路、樹叢石頭裝飾、流動河水、木橋、暗角；塔是有正面和頂面的立體城堡、會飄的旗子、被打到閃白光，倒了變碎石並冒煙
  - 單位：影子、隊伍顏色底座、下場時從空中落下、走路晃動、轉向、受傷閃白；死掉冒煙
  - 特效：塔射出的箭有弧線、法師火球、砲彈、爆炸火光、粒子（煙塵、火花、碎石）、畫面震動、傷害數字
  - 卡牌依類型配色（進攻核心金色、一般部隊藍色、空中青色、法師紫色、輔助綠色、建築灰色），聖水不夠時卡牌會隨聖水「充能」
  - 聖水條 10 格分開填滿；教練是頭像＋對話框，文字有打字效果
  - 音效用 Web Audio 即時合成（不使用音效檔），可以關掉
  - 電腦（寬 860 px 以上）：競技場在左邊放大，右側是 HUD、手牌、教練、「剋制小抄」；手機：直式排列

## 四、核心規則

| 項目 | 設定 |
|---|---|
| 聖水 | 上限 10，開局 5，每 2.8 秒回復 1 點 |
| 塔 | 雙方各 3 座：2 座公主塔（每條路一座）＋ 1 座國王塔（後方正中央） |
| 對戰時間 | 3 分鐘，無延長賽 |

### 塔的數值

| 塔 | 血量 | 傷害 | 攻速(秒) | 射程 | 說明 |
|---|---|---|---|---|---|
| 公主塔 | 1000 | 36 | 0.8 | 150（7.5 格） | 攻擊範圍內最近的敵方單位（地面和空中都可以） |
| 國王塔 | 1580 | 36 | 1.0 | 140（7 格） | 同上；一直都會攻擊（不做原遊戲的「受擊才啟動」） |

> 數值參考原遊戲 11 級：血量和傷害統一 ÷3.05（讓公主塔維持 1000 血），射程用格數 × 20 px。塔的射程從塔中心算；單位打塔時，射程從塔的邊緣（受攻擊範圍 35 px）算。

### 勝負判定

1. 任一方國王塔血量歸 0 → 對方**立刻獲勝**
2. 時間到 → 比較「摧毀敵方塔的數量」，多者勝
3. 塔數相同 → 比較己方剩餘塔血總和，高者勝；仍相同才算平手

### 塔的攻擊目標

- 單位預設攻擊**自己所在路線的敵方公主塔**
- 該路公主塔被摧毀後，這一路的單位改為朝**敵方國王塔**前進並攻擊

### 手牌循環

- 固定 8 張牌組，開局隨機洗牌
- 手上 4 張，另有 1 張「下一張」預覽，其餘在牌隊裡
- 出牌後，該牌進入牌隊尾端，「下一張」補進手牌，牌隊最前面的牌成為新的「下一張」

### 下牌方式

1. 點選一張手牌（高亮），可下牌的區域會亮起來
2. 點可下牌區域的任意位置，單位就出現在**點的位置**，並攻擊離它最近那一路的塔（過河時走那一路的橋）
   - 可下牌區域：自己半場（河的下方，包含國王塔後面），但不能下在河裡或塔上
   - 敵方某一路公主塔被摧毀後，那一路的敵方半場前段（從河邊到離敵方底線 170 px）也可以下牌
   - 開場倒數 3 秒期間不能下牌
3. 聖水不足的牌顯示灰色，點了不會有反應，並顯示「聖水不夠」提示
4. 再點一次已選的牌可取消選取

### 單位基本行為

- 沿所在路線往目標前進，過河時走橋（除非有「跳河」能力，見下方）
- 射程內有可攻擊的敵方單位就打最近的那個；沒有就繼續前進；到塔的範圍內就攻擊塔
- 單位血量歸 0 就消失

## 五、進攻核心單位（Win Condition）

**定義**：傷害高、**不會被路上的敵方單位分心**、直接去打塔的單位。

**牌組規則**：8 張牌裡至少放 2 張進攻核心單位。本牌組有 2 張：🐗 衝鋒豬、💣 炸彈兵。（🛡️ 坦克改成會打單位的「前排肉盾」，不算進攻核心）

**設計參考**：原遊戲中「速度很快、只打建築、可以跳河」的主力推塔單位。數值是依原版 11 級比例縮放成本遊戲的尺度（血量和傷害 ÷3.05，射程 1 格 = 20 px，移速依原遊戲速度等級換算），不是照抄。

| 進攻核心單位 | 風格 | 怎麼用 | 怎麼防 |
|---|---|---|---|
| 🐗 衝鋒豬 | 快、只打建築、跳河 | 對手聖水少時直接衝塔；或跟在坦克後面 | 砲塔引開、小兵群攔截、法師輸出、靠塔打 |
| 💣 炸彈兵 | 衝塔自爆，一次性高傷害 | 用來補最後一擊，或炸掉塔前的敵方單位群 | 砲塔引開、小兵群在半路擊殺 |

**核心配合**：🛡️ 坦克（前排肉盾）先走、🐗 衝鋒豬跟後面。公主塔會先打最近的坦克，衝鋒豬就能多打幾下；坦克也會順手處理來防守的敵方單位。再加上 💚 遠程治療師補血，坦克能撐更久。

## 六、牌組（8 張，含自創單位）

| 牌 | 費用 | 數量 | 血量 | 傷害 | 攻速(秒) | 射程 | 移速 | 類型 | 特色 |
|---|---|---|---|---|---|---|---|---|---|
| 🔫 砲塔 | 3 | 1 | 270 | 70 | 0.9 | 110 | — | **建築** | 不會移動，30 秒後消失（血量隨時間減少）；只打地面；**吸引衝鋒豬、炸彈兵**（參考加農砲） |
| 👥 小兵群 | 3 | 3 | 66 | 39 | 1.1 | 近戰 | 40 | 地面 | 一次出 3 隻並排，數量多（參考哥布林） |
| 💣 炸彈兵（自創） | 3 | 1 | 160 | — | — | — | 38 | 地面 | **進攻核心**；只衝塔，到塔就自爆；被攻擊後開始倒扣血並加速，血歸 0 也會爆 |
| 🦇 蝙蝠群（自創） | 3 | 3 | 27 | 27 | 1.2 | 近戰 | 40 | **空中** | 一次出 3 隻，**只有法師、塔（和其他空中單位）打得到**（參考蝙蝠） |
| 🧙 法師 | 4 | 1 | 248 | 92 | 1.4 | 110 | 20 | 地面 | **範圍傷害**（半徑 30），可以打空中（參考法師） |
| 🐗 衝鋒豬 | 4 | 1 | 556 | 104 | 1.6 | 近戰 | 40 | 地面 | **進攻核心**；只打建築、不理單位、**可以跳河**（參考野豬騎士） |
| 💚 遠程治療師（自創） | 4 | 1 | 220 | 治療 50 | 1.5 | 110 | 20 | 地面 | **不攻擊，只治療友軍**；血少，要保護 |
| 🛡️ 坦克 | 5 | 1 | 1000 | 60 | 3.5 | 近戰 | 20 | 地面 | **前排肉盾**；很耐打但打得很慢，會打單位也會打塔（不是只打塔） |

- 平均費用 3.625（第 3 版用 3 費砲塔換掉 2 費快跑兵，原本 3.5），結算時會顯示
- 近戰射程約 18 px；塔的受攻擊範圍約 35 px；單位的身體半徑約 10 px
- 移速換算：原遊戲很慢/慢/中/快/很快（30/45/60/90/120）→ 每秒 10/15/20/30/40 px
- 索敵範圍 110 px（5.5 格）：範圍內看到可攻擊的敵方單位會追過去打（只打塔的單位、炸彈兵、治療師除外）
- 以上數值是初始值，之後依試玩調整

### 特殊規則細節

- **空中單位**：地面近戰單位（小兵群、衝鋒豬、坦克）和砲塔打不到；只有法師、塔（和其他空中單位）可以攻擊。空中單位可以飛過河，不用走橋
- **範圍傷害**：法師的攻擊對目標周圍半徑 30 內的**所有敵方單位**造成傷害（地面和空中都算）
- **只打建築（不理單位）**：衝鋒豬（和炸彈兵）不會因為路上有敵方單位而停下或轉向，直接前往**最近的敵方建築**（自己這一路的塔，或比塔更近的砲塔）；但敵方單位和塔可以攻擊它
- **🔫 砲塔（建築）**：放下後不會移動，血量在 30 秒內慢慢減少到 0 後消失；攻擊射程內最近的敵方地面單位；一般單位會把它當成可攻擊的目標；炸彈兵炸到它造成 300（和塔一樣，範圍從砲塔邊緣算）；治療師不會補它
- **跳河**：衝鋒豬不需要繞到橋上，可以直接在所在的路線上過河
- **炸彈兵**：不攻擊單位，直接走向目標塔；**被塔打到**之後開始「倒扣血」（每秒 34）並加速為 2 倍（被單位打不會加速，所以小兵群、砲塔攔得住）；進入塔的範圍或血歸 0 時自爆，半徑 40 內（對塔從塔的邊緣算），對塔 300 傷害、對敵方地面單位 150 傷害，炸彈兵本身消失；不傷害己方
- **遠程治療師**：
  - 每 1.5 秒，治療射程（110 px，約 5.5 格）內「血量比例最低」的友軍 50 點，不超過血量上限
  - 地面和空中友軍都可以治療；不能治療自己，也不能治療塔
  - 平常跟在最近的友軍後方約 60 px；沒有友軍時，像一般單位一樣往敵方塔前進（會過河），走到塔的射程內就停下，讓對方有機會解掉它
  - 治療時，治療師和目標之間畫一條綠線，玩家看得出在補誰
  - 治療量（約每秒 33）低於公主塔傷害（約每秒 45），光靠補血頂不住塔，要搭配輸出
  - 不攻擊，但敵方單位和塔會攻擊它

### 單位互動（設計目的）

| 組合 | 結果 | 原因 |
|---|---|---|
| 小兵群 vs 衝鋒豬 | 小兵群佔優 | 數量多、攻速快，能很快把衝鋒豬打掉 |
| 法師 + 塔 vs 衝鋒豬 | 防守方佔優 | 衝鋒豬不理單位，邊衝邊被法師和塔打 |
| 衝鋒豬 + 坦克 | 進攻方佔優 | 塔先打坦克，衝鋒豬多打幾下 |
| 坦克 + 治療師 | 進攻方佔優 | 坦克被補血，在塔前撐更久 |
| 法師 vs 小兵群 / 蝙蝠群 | 法師佔優 | 範圍傷害一次打多隻 |
| 砲塔 vs 蝙蝠群 | 蝙蝠群佔優 | 砲塔只打地面，蝙蝠可以直接拆掉它 |
| 砲塔 vs 衝鋒豬 | 防守方佔優 | 衝鋒豬被吸去打砲塔，塔不會掉血 |
| 法師 vs 坦克 | 法師佔優 | 坦克攻速很慢（3.5 秒），法師撐得到把它打完 |
| 小兵群 vs 坦克 | 小兵群佔優 | 數量多、攻速快，坦克打得很慢，來不及清完小兵 |
| 炸彈兵 vs 塔 / 單位群 | 炸彈兵佔優 | 一次爆炸傷害高 |
| 砲塔 vs 炸彈兵 | 砲塔佔優 | 炸彈兵被吸過去，在半路就被砲塔打爆 |
| 治療師 vs 法師 / 炸彈兵 | 治療師吃虧 | 血量少，範圍傷害和爆炸一次就打到 |

## 七、電腦對手（第 2 版）

- 有自己的聖水（規則與玩家完全相同，不作弊）
- 每隔 3～6 秒（隨機）嘗試出一張負擔得起的牌
- 在自己半場隨機選一條路線下牌
- 開局前 5 秒不出牌，給玩家反應時間
- **會防守**：玩家單位過河後約 0.8 秒，電腦會從手牌挑剋制它的牌（依剋制關係表），下在那個單位和塔之間；有剋制牌但聖水不夠會等最多 4 秒，手上沒有剋制牌就交給塔處理
- 防守時不隨機出牌

## 八、新手教學提示（第 3 版）

畫面上有一塊固定的「教練提示」區，依事件顯示一句白話提示：

| 時機 | 提示 |
|---|---|
| 開局 | 「點一張牌，再點你的半場來下牌」 |
| 每張牌第一次下牌後 | 說明該牌的特色（見牌組表）；如果同時聖水不到 1，先顯示花光聖水的提示，下次再出這張才介紹 |
| 聖水到 10 且停留超過 2 秒 | 「聖水滿了會浪費，趕快出牌」（每次滿只提醒一次） |
| 聖水不足時點牌 | 「聖水不夠，等一下再出」 |
| 出牌後聖水不到 1 | 「花光聖水會讓你沒辦法應對，留一點」 |
| 敵方出 🐗 衝鋒豬 | 「衝鋒豬跑很快、只打建築。用砲塔把它引開、用小兵群去攔，或靠法師和塔來打」 |
| 敵方出 🛡️ 坦克 | 「坦克很耐打但打得很慢，用小兵群圍毆或法師來對付」 |
| 敵方出 🛡️ 坦克後接 🐗 衝鋒豬 | 「他們在配合：坦克吸引塔，衝鋒豬跟在後面，先處理衝鋒豬」 |
| 敵方出 🦇 蝙蝠群 | 「蝙蝠在空中，近戰打不到，要用法師」 |
| 敵方出 👥 小兵群 | 「小兵群數量多，法師的範圍傷害很有效」 |
| 敵方出 💣 炸彈兵 | 「炸彈兵會衝塔自爆，用砲塔把它引開，或用小兵群在半路攔住」 |
| 敵方出 💚 遠程治療師 | 「治療師會幫對手補血，優先用法師打掉它」 |
| 敵方出 🔫 砲塔 | 「你的衝鋒豬、炸彈兵會被它吸過去，可以先拆掉它或等它時間到消失」 |
| 敵方一邊公主塔被拆 | 「這條路的公主塔倒了，現在可以集中打國王塔」 |

- 敵方出牌的提示，**每種牌整場只提示一次**（坦克接衝鋒豬的配合提示也只一次，條件是坦克出完 10 秒內出衝鋒豬）

### 結算畫面
